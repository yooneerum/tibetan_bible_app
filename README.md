# 📖 Tibetan Bible App
> Offline Tibetan New Testament Reader built with Flutter.

![Platform](https://img.shields.io/badge/Platform-Android-green)
![Flutter](https://img.shields.io/badge/Flutter-3.x-blue)
![License](https://img.shields.io/badge/License-Non--Commercial-lightgrey)

A simple and offline Tibetan Bible application built with Flutter.

This app is designed for native Tibetan speakers and learners who want to read the **New Testament (Spoken Language Version, Lhasa Dialect)** anytime, even without an internet connection.

---

## ✨ Features

- 📚 Read the Tibetan New Testament completely offline
- 🔍 Search verses by keyword
- ❤️ Bookmark favorite verses
- 🖍 Highlight verses with multiple colors
- 📜 Automatically save reading history
- 📋 Copy verses to the clipboard
- 🌙 Light & Dark mode
- 🔠 Adjustable font size
- ⚡ Fast local SQLite database
- 📱 Clean and simple user interface

## 📦 Installation (Android)

1. Download the latest **APK** from the **Releases** page.
2. Transfer the APK to your Android device if necessary.
3. Enable **Install unknown apps** (if prompted).
4. Install the APK.
5. Open the app and enjoy reading the Tibetan Bible offline.
